# Ручная проверка на Windows перед выпуском

Автоматические тесты не запускают реальный трей, звуковые устройства, программы трансляции и установщик. Пройдите этот список на чистой или близкой к чистой машине и отметьте результат. Если пункт не прошёл, приложите журнал из `%LOCALAPPDATA%\LocalAssistant\` (в нём нет текста распознанной речи).

Среда: Windows 10 2004+ / Windows 11, версия приложения из окна «О программе»: ________

## 1. Запуск и трей

- [ ] Нет кнопки на панели задач; нет окна в Alt+Tab; значок есть в трее (или под стрелкой `^`).
- [ ] Клик по значку показывает/скрывает окно; правый клик открывает меню (показать/скрыть, пауза, озвучка, настройки, выход).
- [ ] Кнопка «закрыть» сворачивает в трей, приложение продолжает слушать.
- [ ] Повторный запуск `LocalAssistant.exe` показывает уже работающее окно, второй копии нет (Диспетчер задач).
- [ ] «Выход» завершает процесс; значок исчезает из трея сразу.
- [ ] Выход из Windows или выключение не блокируется приложением.

## 2. Скрытие от трансляции (главная функция)

Проверьте каждым способом, которым пользуетесь (OBS «захват экрана» и «захват окна», Zoom/Teams/Discord «весь экран» и «окно», Win+Shift+S, Print Screen, запись Xbox Game Bar).

- [ ] «Настройки → Окно → Статус защиты» показывает «Активно» (на Windows 10 2004+).
- [ ] Главное окно **отсутствует** в трансляции/записи/снимке.
- [ ] Контекстное меню (`⋯`), выпадающие списки в настройках, подсказки при наведении **отсутствуют**.
- [ ] Окна «Настройки», «История», «База знаний», «Центр диагностики», «Журнал фильтра» **отсутствуют**.
- [ ] Диалог выбора документов (База знаний → Добавить) выглядит как диалог Qt и **отсутствует** в трансляции.
- [ ] «Открыть папку данных» предупреждает о Проводнике; после согласия Проводник **виден** в трансляции (это ожидаемо).
- [ ] Горячая клавиша «Показать/скрыть» (`Ctrl+Alt+H`) при открытых «Настройки»/«База знаний» убирает **все** окна приложения.
- [ ] Значок в трее и панель задач при демонстрации **всего экрана** видны (это ограничение Windows); при демонстрации отдельного окна — нет.
- [ ] Выключите «Скрывать окно…» — окна становятся видны в трансляции; включите — снова скрыты.
- [ ] Много раз откройте и закройте меню и подсказки, затем повторите проверку: ни одно новое окно не «просвечивает».

## 3. Аудио

- [ ] Системный звук: включите видео с речью — фразы появляются в «Журнале фильтра».
- [ ] Смена устройства вывода (колонки ↔ наушники) во время работы: захват переключается сам, статус это отражает.
- [ ] Микрофон: включите, разрешите доступ в Windows, скажите фразу — она распознаётся.
- [ ] Озвучка: пока помощник говорит, он не распознаёт собственный голос; `Esc` прерывает речь.
- [ ] Пауза (`Ctrl+Shift+Space`) останавливает распознавание, повторное нажатие возобновляет.

## 4. Ответы и данные

- [ ] Ollama запущена: ответ приходит потоком; «Стоп» останавливает; повтор ответа работает.
- [ ] Ollama остановлена: понятная ошибка, «Проверить Ollama» восстанавливает работу после запуска.
- [ ] База знаний: импорт PDF, DOCX и TXT; поиск находит текст; удаление документа не удаляет исходный файл.
- [ ] Центр диагностики показывает Ollama, модели, источники звука; скопированный отчёт не содержит текста переписки.
- [ ] В `live_assistant.log` нет распознанной речи.

## 5. Сборка и установка

- [ ] Артефакт CI запускается на машине без Python.
- [ ] Установщик (если собирается): установка без прав администратора, ярлык в «Пуске», галочка автозапуска работает, деинсталляция удаляет программу и оставляет данные в `%LOCALAPPDATA%\LocalAssistant`.
- [ ] После перезагрузки с включённым автозапуском приложение стартует свёрнутым в трей.
