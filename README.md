# LocalAssistantRefactor — dark glass chat

Модульный локальный голосовой ассистент: PySide6, SoundCard loopback, faster-whisper и Ollama.

## Возможности

Build: `2026.11.11-r7`

- Полупрозрачный тёмный интерфейс с попыткой включить Windows Acrylic.
- Чат с Markdown-ответами (код, списки, заголовки, таблицы), анимацией сообщений и индикатором генерации.
- Потоковый вывод Ollama, кнопка остановки генерации, копирование ответа и повтор последнего ответа.
- Отдельный поток захвата/распознавания аудио и очередь обработки речевых фраз.
- Правила фильтрации и локальная классификация неоднозначных фраз.
- История диалогов в SQLite: новый диалог, переименование, удаление, переключение, поиск по тексту сообщений.
- JSON-настройки под `%LOCALAPPDATA%\LocalAssistant\settings.json`.
- База чатов под `%LOCALAPPDATA%\LocalAssistant\conversations.sqlite3`.
- Настройки (вкладки «Модели», «Голос», «Окно», «Ассистент»): адрес Ollama, модели, размер контекста, температура, системный промпт, устройство и размер Whisper (CPU/CUDA), имена ассистента, порог речи, горячая клавиша, прозрачность, режимы окна и приватность. Список моделей Ollama подгружается в фоне.

## Что нового в r7

**Функции**
- Многострочное поле ввода (Enter — отправить, Shift+Enter — новая строка), растёт вместе с текстом.
- Окно истории с живым поиском по названиям и тексту сообщений (`Ctrl+K`); экспорт диалога в Markdown (`Ctrl+E`).
- Горячие клавиши: `Ctrl+N` новый диалог, `Ctrl+K` история, `Ctrl+,` настройки, `Ctrl+L` фокус на ввод, `Esc` остановить генерацию.
- Блоки `<think>…</think>` моделей-рассуждателей скрываются в чате и не попадают обратно в контекст.
- Явный `num_ctx` (по умолчанию 8192): Ollama иначе молча обрезает длинные диалоги, теряя системный промпт.
- Проверка Ollama при запуске: понятное сообщение, если сервер не запущен или модель не скачана; при 404 подсказывается `ollama pull`.
- «Повторить ответ» больше не теряет старый ответ, если новая генерация не удалась.
- Очередь голосовых фраз ограничена (2): во время долгого ответа не копятся устаревшие вопросы; «Стоп» очищает очередь.
- Ошибки классификатора показываются в статусе, а не спамят чат при фоновом аудио.
- Расширенный фильтр галлюцинаций Whisper («Субтитры сделал…», «Спасибо за просмотр» и т. п.) и отсев ненадёжных сегментов.
- Pre-roll перед фразой (не обрезается начало слова); во время паузы звуковое устройство продолжает вычитываться, поэтому после возобновления нет лавины старого звука.
- Настройки проверяются и приводятся к допустимым значениям; повреждённый `settings.json` сохраняется как `.bad`.
- Положение и размер окна запоминаются; переключатель «Скрывать окно от захвата экрана».
- Лог в `%LOCALAPPDATA%\LocalAssistant\live_assistant.log`.

**Интерфейс**
- Пузыри: у пользователя — акцентный градиент, у ассистента — «стеклянная» карточка; время у каждого сообщения.
- Статус не раздувает шапку (обрезается с «…»); кнопки «Новый диалог» и «История» в шапке; «Стоп» рядом с «Отправить».
- Волна перенесена в подвал и «гаснет» на паузе; подсказка горячей клавиши показывает реальное сочетание из настроек.
- Автопрокрутка не мешает читать ранние сообщения во время стриминга.
- Тёмные тултипы, вкладки в настройках.

## Запуск в Windows PowerShell

В активном виртуальном окружении из папки проекта:

```powershell
python -m pip install -r requirements.txt
python -m compileall -q main.py assistant tests
python -m unittest discover -s tests -v
python main.py
```

В Ollama должны быть доступны модели, указанные в настройках. Изначально используется `qwen3-coder:30b` и для ответов, и для классификатора; это можно поменять в меню `⋯` → `Настройки`.

Горячая клавиша по умолчанию — `Ctrl+Shift+Space`. Ручные сообщения в поле ввода обходят фильтр голосового намерения, а голосовые фразы сперва проверяются фильтром.

## Файлы

- `main.py` — запуск Qt.
- `assistant/ui.py` — чат, Markdown, анимации, меню, Acrylic и управление окном.
- `assistant/audio_worker.py` — захват системного звука и Whisper.
- `assistant/processor.py` — последовательная очередь фраз, отмена и потоковая генерация.
- `assistant/ollama_client.py` — NDJSON streaming API, классификация, список моделей, отмена активного HTTP-запроса.
- `assistant/speech_filter.py` — правила и защита от дублей.
- `assistant/conversation_store.py` — SQLite.
- `assistant/settings_store.py` — настройки в JSON.
- `assistant/settings_dialog.py` — окно настроек (вкладки).
- `assistant/history_dialog.py` — окно истории с поиском.
- `assistant/segmenter.py` — выделение фраз из аудиопотока и отсев ненадёжных сегментов Whisper (без Qt и аудио, покрыто тестами).
- `assistant/text_utils.py` — `<think>`-блоки, форматирование времени и имён файлов.
- `assistant/config.py` — значения по умолчанию для совместимости.

## Примечания

- Окно исключается из поддерживаемых API захвата экрана только best-effort; это не гарантирует скрытие в каждом приложении видеосвязи.
- Windows Acrylic использует недокументированный API и может не работать на некоторых версиях Windows; резервный тёмный полупрозрачный фон остаётся.
- При выборе другого аудиоустройства или размера Whisper аудиопоток перезапускается, поэтому загрузка Whisper может занять несколько секунд.
- Юнит-тесты не требуют Qt и аудио (`python -m unittest discover -s tests`); сам интерфейс нужно проверять вручную.
- Синтаксическая проверка не заменяет тест на компьютере с фактическим аудиоустройством и работающим Ollama.
