# LocalAssistantRefactor — dark glass chat

Модульный локальный голосовой ассистент: PySide6, SoundCard loopback, faster-whisper и Ollama.

## Возможности

Build: `2026.10.21-r11`

- Полупрозрачный тёмный интерфейс с попыткой включить Windows Acrylic.
- Чат с Markdown-ответами (код, списки, заголовки, таблицы), анимацией сообщений и индикатором генерации.
- Потоковый вывод Ollama, кнопка остановки генерации и повтор последнего ответа.
- Отдельный поток захвата/распознавания аудио и очередь обработки речевых фраз.
- Правила фильтрации и локальная классификация неоднозначных фраз.
- История диалогов в SQLite: новый диалог, переименование, удаление, переключение, поиск по тексту сообщений.
- JSON-настройки под `%LOCALAPPDATA%\LocalAssistant\settings.json`.
- База чатов под `%LOCALAPPDATA%\LocalAssistant\conversations.sqlite3`.
- Профили «Помощник-программист», «Обучение с подсказками» и «Универсальный / автоопределение»; ограниченный контекст выбранной папки проекта с исключением типичных файлов секретов и каталогов сборки.
- Источник распознавания: системный звук или физический микрофон; режимы постоянного прослушивания, переключения горячей клавишей и push-to-talk; настраиваемые чувствительность, пауза и максимальная длина фразы.
- Озвучивание ответов через локальный Windows Speech API с возможностью прервать воспроизведение; функция выключена по умолчанию.
- Многострочный ввод кода и traceback (`Shift+Enter` — новая строка, `Enter` — отправить).
- Действия с пользовательским сообщением отображаются компактными иконками «Изменить» и «Повторить» с подсказками; под ответом ассистента оставлена только иконка повторной генерации, кнопки «Копировать», «Код» и «Голос» убраны.
- Редактирование любого пользовательского сообщения с удалением зависимых последующих ходов и повторной генерацией; закрепление важных диалогов.
- Колёсико мыши прокручивает переписку, даже если курсор находится над текстом сообщения или кнопками действий.
- Отдельная глобальная горячая клавиша для вызова окна помощника; `Ctrl+L` фокусирует ввод, `Ctrl+N` создаёт чат, `Escape` останавливает генерацию или озвучивание.
- Настройки моделей, языка и размера Whisper, горячей клавиши, плотности и насыщенности фона, компактного режима и закрепления поверх окон.
- Системный трей Windows: открыть окно двойным щелчком, поставить прослушивание на паузу или выйти через контекстное меню; опционально закрывать окно без завершения работы.

## Запуск в Windows PowerShell

В активном виртуальном окружении из папки проекта:

```powershell
python -m pip install -r requirements.txt
python -m compileall -q main.py assistant tests
python -m unittest discover -s tests -v
python main.py
```

В Ollama должны быть доступны модели, указанные в настройках. Изначально используется `qwen3-coder:30b` и для ответов, и для классификатора; это можно поменять в меню `⋯` → `Настройки`.

Горячая клавиша прослушивания по умолчанию — `Ctrl+Shift+Space`; глобальный вызов окна — `Ctrl+Shift+A`. Контекст выбранного проекта выключен по умолчанию: чтобы передавать исходники локальной модели, выбери папку и включи соответствующий переключатель в настройках. Ручные сообщения в поле ввода обходят фильтр голосового намерения, а голосовые фразы сперва проверяются фильтром.

## Файлы

- `main.py` — запуск Qt.
- `assistant/ui.py` — чат, Markdown, анимации, меню, Acrylic, история, редактирование сообщений и горячие клавиши.
- `assistant/chat_input.py` — многострочный редактор сообщений и кода.
- `assistant/audio_worker.py` — захват системного звука и Whisper.
- `assistant/processor.py` — последовательная очередь фраз, отмена, потоковая генерация, профили помощника и контекст проекта.
- `assistant/coding_mode.py` — классификация типичных намерений в запросах о коде.
- `assistant/project_context.py` — ограниченное чтение файлов выбранной папки.
- `assistant/speech_output.py` — локальное озвучивание ответов средствами Windows.
- `assistant/ollama_client.py` — NDJSON streaming API, классификация, список моделей, отмена активного HTTP-запроса.
- `assistant/speech_filter.py` — правила и защита от дублей.
- `assistant/conversation_store.py` — SQLite.
- `assistant/settings_store.py` — настройки в JSON.
- `assistant/settings_dialog.py` — окно настроек.
- `assistant/config.py` — значения по умолчанию для совместимости.

## Примечания

- Окно исключается из поддерживаемых API захвата экрана только best-effort; это не гарантирует скрытие в каждом приложении видеосвязи.
- Windows Acrylic использует недокументированный API и может не работать на некоторых версиях Windows; резервный тёмный полупрозрачный фон остаётся.
- При выборе другого аудиоустройства или размера Whisper аудиопоток перезапускается, поэтому загрузка Whisper может занять несколько секунд.
- Синтаксическая проверка не заменяет тест на компьютере с фактическим аудиоустройством и работающим Ollama.
